# 💚 LifeScore — Health Assessment & Life Expectancy Prediction
 
> A desktop application that collects health and lifestyle data through a guided multi-step form and uses a trained machine learning model to predict life expectancy.

---

## Features
 
- **Multi-step wizard UI** — 3 pages (Personal → Lifestyle → Medical) with a visual progress stepper
- **Automatic unit conversion** — Height entered in feet/inches is converted to centimetres; weight entered in pounds is converted to kilograms
- **BMI auto-calculation** — Computed from height and weight if left blank
- **Dropdown fields** — Combobox widgets for categorical inputs to prevent data entry errors
- **Styled Tkinter UI** — Custom color theme, flat buttons, card layout, and consistent typography
- **ML prediction** — Logistic regression model loaded from `.joblib` at runtime
- **Result popup** — Clean modal window displaying the predicted life expectancy

## Input Variables
 
| Variable | Type | Notes |
|---|---|---|
| Gender | Categorical | Female / Male |
| Age | Numeric | Years |
| Height | Numeric | Entered as ft + in, converted to cm |
| Weight | Numeric | Entered in lbs, converted to kg |
| BMI | Numeric | Auto-calculated if blank |
| Physical Activity | Categorical | Low / Medium / High |
| Smoking Status | Categorical | Never / Former / Current |
| Alcohol Consumption | Categorical | None / Moderate / High |
| Diet | Categorical | Poor / Average / Healthy |
| Blood Pressure | Categorical | Low / Normal / High |
| Cholesterol | Numeric | mg/dL |
| Diabetes | Binary | Yes → 1 / No → 0 |
| Hypertension | Binary | Yes → 1 / No → 0 |
| Heart Disease | Binary | Yes → 1 / No → 0 |
| Asthma | Binary | Yes → 1 / No → 0 |

## Model Details
 
| Property | Value |
|---|---|
| Algorithm | Logistic Regression |
| Library | scikit-learn |
| Model file | `lrmodel.joblib` |
| Preprocessor file | `preprocessor.joblib` |
| Input | pandas DataFrame (1 row, 15 features) |
| Output | Predicted life expectancy (float, years) |
 
The preprocessor handles feature scaling and encoding before the model receives the data.
